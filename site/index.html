Detecte e contenha ransomware em servidores Windows.

Detect and contain ransomware on Windows servers.

Quando alguém, a partir de outra máquina, começa a cifrar, regravar ou apagar arquivos em massa nos compartilhamentos do servidor, o RansomGuard identifica a conta e o IP e, se você permitir, corta o acesso. Agente e painel rodam na sua rede; cada ação tem Desfazer.

When someone on another machine starts encrypting, overwriting or deleting files in bulk on the server's shares, RansomGuard identifies the account and the IP and, if you allow it, cuts the access. Agent and dashboard run in your network; every action has Undo.

Para que serveWhat it is for

O ataque pode começar em outra máquina. Seus arquivos continuam em risco.

The attack can start on another machine. Your shared files are still at risk.

Uma estação comprometida pode usar uma conta com acesso aos compartilhamentos para alterar arquivos pela rede. Monitorar o servidor de destino acrescenta uma camada à proteção das estações.

A compromised workstation can use an account with share access to modify files over the network. Monitoring the destination server adds a layer alongside endpoint protection.

Policy-driven containment

In Block mode, only for High-confidence incidents. Monitor mode, allowlists and learning help reduce false positives but require validation in your environment.

Como funcionaHow it works

Observa o servidor, atribui o ataque, contém e deixa desfazer.

Watches the server, attributes the attack, contains it and lets you undo.

Observa

Watches

Eventos de auditoria do Windows, arquivos-canário nas pastas que você indicar, file screens do FSRM e as cópias de sombra.

Windows audit events, canary files in the folders you choose, FSRM file screens and shadow copies.

Atribui

Attributes

Agrupa a atividade por conta, IP de origem e compartilhamento, e dá um nível: Média ou Alta.

Groups activity by account, source IP and share, and assigns a level: Medium or High.

Contém

Contains

Em modo Block, só para Alta: bloqueia o IP, nega a conta no compartilhamento, derruba a sessão SMB e cria uma cópia de sombra.

In Block mode, High only: blocks the IP, denies the account on the share, drops the SMB session and takes a shadow copy.

Deixa desfazer

Lets you undo

Cada ação confere o próprio efeito e tem Desfazer no painel. O padrão de tudo é Monitor: só registra.

Each action verifies its own effect and has Undo in the dashboard. The default for everything is Monitor: it only records.

Agente

Agent

Serviço do Windows em cada servidor de arquivos. Detecta e contém localmente, mesmo com o painel fora do ar.

A Windows service on each file server. Detects and contains locally, even with the dashboard down.

Painel

Dashboard

Serviço do Windows na sua rede: incidentes, nota de risco, política assinada, blocklist entre servidores e alertas (ntfy, Teams/Slack, Telegram, e-mail).

A Windows service in your network: incidents, risk score, signed policy, blocklist across servers and alerts (ntfy, Teams/Slack, Telegram, e-mail). Interface in Portuguese.

Catálogo

Catalog

Extensões e notas de resgate conhecidas, assinado offline e verificado antes de valer. A versão nunca regride.

Known extensions and ransom notes, signed offline and verified before use. The version never goes back.

Instalar

Install

  1. Instale o painel e abra https://<painel>:5001. Crie a conta de administrador com o token de primeira execução.
  2. Na tela Agentes, gere um token de enrolamento: o painel mostra o comando do agente pronto.
  3. Rode o comando em cada servidor de arquivos, com as pastas a proteger.
  4. Fique em Monitor alguns dias. Preencha a allowlist e só então teste Block num servidor de teste, com o ensaio.
  1. Install the dashboard and open https://<dashboard>:5001. Create the administrator account with the first-run token.
  2. On the Agentes page, generate an enrollment token: the dashboard shows the agent command, ready.
  3. Run the command on each file server, naming the folders to protect.
  4. Stay in Monitor for a few days. Fill the allowlist and only then try Block on a test server, with the drill.

Perguntas frequentesFAQ

Antes de instalar

Before installing

Substitui antivírus, EDR ou backup?Does it replace antivirus, EDR or backup?

Não. Ele não impede a execução do ransomware na estação nem protege máquinas sem agente. Ele observa o servidor e contém quem ataca os compartilhamentos. Mantenha antivírus ou EDR e backup offline.

No. It does not stop ransomware from running on the workstation or protect machines without an agent. It watches the server and contains whoever attacks the shares. Keep antivirus or EDR and offline backup.

Como reduzir o acesso de uma estação comprometida ao servidor?How can I limit a compromised workstation's access to a server?

O RansomGuard age nos servidores onde há agente; não impede a estação de alcançar outros servidores. O IPsec Studio ajuda a planejar, simular e implantar isolamento por grupo na rede. Cada projeto funciona sozinho; a política IPsec leva tempo para chegar às máquinas.

RansomGuard acts on servers with an agent; it cannot prevent the workstation from reaching other servers. IPsec Studio helps plan, simulate and deploy group-based network isolation. Each project works independently; IPsec policy takes time to reach the machines.

Serve para qualquer servidor Windows?Does it work for any Windows server?

A cobertura é a dos compartilhamentos de arquivos e das pastas monitoradas: auditoria, canários e FSRM nesses lugares. Um servidor com outras funções pode ter o agente, mas isso não significa proteção especializada para SQL Server, AD ou Hyper-V.

Coverage is that of file shares and monitored folders: auditing, canaries and FSRM in those places. A server with other roles can run the agent, but that does not mean specialized protection for SQL Server, AD or Hyper-V.

Pode conter meu backup por engano?Could it contain my backup by mistake?

Pode, se a conta do backup ou do sincronizador regravar muitos arquivos existentes e estiver fora da allowlist. Por isso o padrão é Monitor: observe o seu ambiente, preencha a allowlist e só então use Block.

It can, if the backup or sync account overwrites many existing files and is not on the allowlist. That is why the default is Monitor: observe your environment, fill the allowlist and only then use Block.

Quanto custa? Tem suporte?How much does it cost? Is there support?

Nada: é gratuito e de código aberto (MIT), com todos os recursos, inclusive a contenção. A manutenção é voluntária e sem SLA; problemas e sugestões vão como issues no GitHub, e vulnerabilidades pelo canal privado descrito no SECURITY.md.

Nothing: it is free and open source (MIT), with every feature, containment included. Maintenance is voluntary, with no SLA; problems and suggestions go as GitHub issues, and vulnerabilities through the private channel described in SECURITY.md.

Precisa de internet?Does it need the internet?

Detecção e contenção acontecem no servidor, sem internet. O painel busca o catálogo assinado no GitHub e envia as notificações que você configurar; sem acesso, ele mantém o último catálogo válido.

Detection and containment happen on the server, without internet. The dashboard fetches the signed catalog from GitHub and sends the notifications you configure; without access, it keeps the last valid catalog.

A cópia de sombra recupera tudo?Does the shadow copy recover everything?

Não necessariamente: a cópia de sombra é criada no momento da contenção, e o que foi cifrado antes dela não volta por ela. Ela também respeita um teto diário e o espaço livre. Backup offline continua sendo a garantia de restauração.

Not necessarily: the shadow copy is taken at containment time, and what was encrypted before it does not come back through it. It also respects a daily ceiling and free space. Offline backup remains the restore guarantee.
